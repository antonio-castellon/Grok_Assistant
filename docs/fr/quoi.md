# Ce que c'est

Au fond, c'est une voix pour les moments où lire devient difficile et où la maison est silencieuse. La version pour ordinateur portable est pensée pour une personne âgée qui dispose déjà d'un petit ordinateur à proximité ; la version Raspberry Pi 4 avec 4 Go propose le même assistant sous la forme d'un appareil dédié lorsqu'on préfère garder le portable fermé. Ce projet parallèle est [Grok Pi Assistance](https://github.com/antonio-castellon/Grok_Pi_Assistance). Le microphone peut rester prêt à écouter, mais l'audio reste local. Seul le texte réellement destiné à l'assistant est envoyé.
