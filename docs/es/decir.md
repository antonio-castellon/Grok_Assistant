# Qué se puede decir

Para empezar, basta con decir `hola grok` o `¿estás ahí?`. Cuando no hay una conversación activa, el resto de órdenes empiezan por `comando`. Las frases de más de seis palabras se ignoran normalmente, salvo que sean un saludo válido o `pon la canción` seguido de un título de hasta dieciséis palabras. Durante una conversación ese límite desaparece. Las peticiones de música no necesitan `comando`, y el adiós se procesa localmente y de inmediato. Mientras llega una respuesta de la nube, el asistente reproduce una frase breve de espera, pausa el micrófono y después lee la respuesta. La ventana de información contiene la lista completa de órdenes.

El asistente vive en la bandeja del sistema. Un clic izquierdo abre la ventana y un clic derecho abre el menú. Cerrar la ventana solo la oculta; para terminar el programa por completo hay que usar **Salir**, desde la ventana o desde el menú de la bandeja.
