# Qué es esto

En esencia, es una voz para esos momentos en los que leer cuesta y la casa está en silencio. La versión para portátil está pensada para una persona mayor que ya tiene un pequeño ordenador cerca; la versión para Raspberry Pi 4 de 4 GB ofrece el mismo asistente como dispositivo dedicado cuando no conviene dejar un portátil abierto. Ese proyecto paralelo es [Grok Pi Assistance](https://github.com/antonio-castellon/Grok_Pi_Assistance). El micrófono puede permanecer preparado, pero el audio se queda en local. Solo se envía fuera el texto que realmente iba dirigido al asistente.
