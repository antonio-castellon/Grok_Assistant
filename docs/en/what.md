# What this is

At its core, this is a voice companion for the moments when reading is difficult and the house is quiet. The laptop version is meant for an older person who already has a small computer nearby; the Raspberry Pi 4 version offers the same assistant as a dedicated device when keeping a laptop open is not ideal. The microphone can remain ready, but audio stays local. Only text that was actually meant for the assistant is sent out.
